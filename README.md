# Khunk — Վիրտուալ Խունկ (Virtual Incense)

A calm, interactive web experience built around a traditional Armenian բուրվառ (burvar / censer).

Click or tap anywhere on the screen and resin grains arc into the censer's tray — sparking embers, brightening the coal glow, and sending photographic smoke drifting across the whole screen. The more grains you add, the thicker the smoke. Sound is synthesized live with the Web Audio API (a soft tink, an ember crackle, an ambient drone with a distant bell), with toggles for sound, dark/light theme, and an info panel about khunk in the Armenian tradition.

## Run it

It's a fully static site — no build step. Serve the folder with any static server, e.g.:

```
npx serve .
```

Deployed on Vercel as a static site (framework preset: Other, no build command).
